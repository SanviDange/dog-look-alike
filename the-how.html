The how


The Doggleganger concept is based on advanced image recognition and machine learning algorithms that analyze facial features and patterns. By comparing a user's photo with a vast database of dog images, the system identifies potential matches and suggests the most likely canine counterparts.


The system uses a combination of facial recognition technology and breed-specific features to find the best match. Once a match is found, users can see a side-by-side comparison of their photo and the dog's photo, highlighting the similarities.

The model makes matches using ml5.js's API for facial camera recognition capabilities, allowing for real-time analysis and matching. ml5.js tracks facial landmarks using points at specific locations on the face, such as the eyes, nose, and mouth, to create a detailed facial profile. The model uses the data from the landmarks to compare the user's facial features with those of dogs in the database, looking for similarities in shape, structure, and proportions.

The dog's landmarks are from the "https://www.kaggle.com/datasets/georgemartvel/dogflw" which compares various facial points on the dog's face. The dataset contains 4335 images of dogs' faces in various environments and conditions, annotated with 46 facial landmarks and a bounding box on the dog’s face.
